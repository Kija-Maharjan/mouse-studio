# Mousepad Studio

Custom print preview tool for mousepad artwork.

## Features

- Drag and drop image upload
- Browse and select artwork file
- Live preview across three pad sizes
- Hover zoom preview for detailed inspection
- Click a canvas to open a larger review modal
- Download proof or order-ready PNG export

## Usage

1. Open `index.html` in your browser.
2. Upload artwork using the button or drag and drop into the upload area.
3. Hover over the preview stages to see a zoomed area.
4. Click any mousepad preview to open the review modal.
5. Download the current proof or place the order.

## Files

- `index.html` — main application markup
- `style.css` — page styling and layout
- `script.js` — upload handling, preview drawing, zoom and review modal
- `.gitignore` — ignored files and folders
